# ShareBite – Shared API Contracts & Specification

This document defines the unified API contracts, request/response formats, error codes, and shared data schemas for the **ShareBite Food Waste Management System**.

All endpoints are hosted at: `http://localhost:5000/api`

---

## 1. Unified Response Envelopes

Every endpoint returns a predictable, standardized envelope.

### 1.1 Success Response Envelope
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Operation completed successfully",
  "data": { ... },
  "meta": {
    "count": 10
  },
  "timestamp": "2026-11-13T10:00:00.000Z"
}
```

### 1.2 Error Response Envelope
```json
{
  "success": false,
  "statusCode": 400,
  "message": "Validation failed",
  "errors": [
    {
      "field": "foodName",
      "message": "Food name must be at least 2 characters"
    }
  ],
  "timestamp": "2026-11-13T10:00:00.000Z"
}
```

## 2. Shared Data Models

### 2.1 Food Entity
| Field | Type | Description | Rules / Enum |
|---|---|---|---|
| `foodId` | `string` | Unique identifier | Generated by database / UUID |
| `foodName` | `string` | Name of the food item | Min 2, max 100 characters |
| `quantity` | `string \| number` | Portion quantity or weight | E.g. `25 portions` or `10 kg` |
| `category` | `string` | Food classification | `Cooked Meals`, `Produce`, `Bakery`, `Dairy`, `Packaged Goods`, `Beverages`, `Other` |
| `donorId` | `string` | User ID of the donating donor | Required |
| `location` | `object` | Pickup address & GPS coordinates | `{ address, city, latitude?, longitude? }` |
| `preparedTime` | `string` | Time food was cooked or packed | ISO-8601 string |
| `pickupDeadline` | `string` | Latest safe time to collect food | ISO-8601 string (`> preparedTime`) |
| `status` | `string` | Food availability lifecycle | `AVAILABLE`, `CLAIMED`, `COMPLETED`, `EXPIRED`, `CANCELLED` |
| `allergens` | `string[]` | Common allergens list | `['Dairy', 'Wheat', 'Gluten', 'None', ...]` |

### 2.2 Food Request Entity
| Field | Type | Description | Rules / Enum |
|---|---|---|---|
| `requestId` | `string` | Unique request identifier | Generated by database / UUID |
| `foodId` | `string` | Foreign key referencing `foodId` | Must reference valid food listing |
| `receiverId` | `string` | User ID of requester (shelter/person) | Required |
| `requestedQuantity` | `number` | Portions or units requested | Positive number |
| `requestStatus` | `string` | Request lifecycle state | `PENDING`, `APPROVED`, `REJECTED`, `COLLECTED`, `CANCELLED` |
| `createdAt` | `string` | Request submission timestamp | ISO-8601 string |

### 2.3 User Profile Entity
| Field | Type | Description | Rules / Enum |
|---|---|---|---|
| `userId` | `string` | Unique identifier (Firebase UID) | Required |
| `name` | `string` | Full name or Organization name | Min 2, max 50 characters |
| `email` | `string` | Valid email address | Standard email regex |
| `role` | `string` | User access privilege | `DONOR`, `RECEIVER`, `VOLUNTEER`, `ADMIN` |

### 3.2 Authentication (Teammate 2 Integration)

#### `POST /api/auth/register`
- **Access:** Public
- **Body:**
```json
{
  "name": "Community Hope Shelter",
  "email": "hope@shelter.org",
  "role": "RECEIVER"
}
```
- **Response `201 Created`:** Returns registered user profile with generated `userId`.

#### `POST /api/auth/login`
- **Access:** Public
- **Body:**
```json
{
  "email": "hope@shelter.org",
  "password": "SecurePassword123"
}
```
- **Response `200 OK`:** Returns `{ token, user }`.

#### `GET /api/auth/me`
- **Access:** Private (`Authorization: Bearer <token>`)
- **Response `200 OK`:** Returns profile of the authenticated user.

#### `POST /api/auth/verify-token`
- **Access:** Public
- **Body:** `{ "token": "firebase_id_token_string" }`
- **Response `200 OK`:** Returns decoded token verification status.

### 3.3 Food Donations (Teammate 3 Integration)

#### `GET /api/donations`
- **Access:** Public
- **Query Params:**
  - `status` (e.g. `AVAILABLE`)
  - `category` (e.g. `Cooked Meals`)
  - `city` (e.g. `Metro City`)
- **Response `200 OK`:** Returns array of food donation objects with metadata `{ count }`.

#### `GET /api/donations/:foodId`
- **Access:** Public
- **Response `200 OK`:** Returns individual donation details or `404 Not Found`.

#### `POST /api/donations`
- **Access:** Private (`Authorization: Bearer <token>`)
- **Body:**
```json
{
  "foodName": "Fresh Vegetable Curry & Rice",
  "quantity": "25 portions",
  "category": "Cooked Meals",
  "donorId": "usr_donor_123",
  "location": {
    "address": "100 University Ave, Community Kitchen",
    "city": "Metro City",
    "latitude": 12.9716,
    "longitude": 77.5946
  },
  "preparedTime": "2026-11-13T08:00:00.000Z",
  "pickupDeadline": "2026-11-13T16:00:00.000Z",
  "status": "AVAILABLE",
  "allergens": ["Dairy"]
}
```
- **Response `201 Created`:** Returns created food document with `foodId`.

#### `PUT /api/donations/:foodId`
- **Access:** Private (Donor / Admin)
- **Body:** Partial or full food object to update.
- **Response `200 OK`:** Returns updated food document.

#### `PATCH /api/donations/:foodId/status`
- **Access:** Private
- **Body:** `{ "status": "CLAIMED" }`
- **Response `200 OK`:** Returns updated donation status.

#### `DELETE /api/donations/:foodId`
- **Access:** Private (Donor / Admin)
- **Response `200 OK`:** Confirms deletion or cancellation.

### 3.4 Food Requests (Teammate 3 Integration)

#### `GET /api/requests`
- **Access:** Private
- **Query Params:** `status`, `foodId`, `receiverId`
- **Response `200 OK`:** Array of request objects.

#### `GET /api/requests/:requestId`
- **Access:** Private
- **Response `200 OK`:** Single request object or `404 Not Found`.

#### `POST /api/requests`
- **Access:** Private (Receivers / Organizations)
- **Body:**
```json
{
  "foodId": "food_001",
  "receiverId": "usr_shelter_456",
  "requestedQuantity": 10,
  "notes": "Will pick up by noon using temperature-controlled bags."
}
```
- **Response `201 Created`:** Created request with `requestId` and status `PENDING`.

#### `PATCH /api/requests/:requestId/status`
- **Access:** Private (Donor / Volunteer / Admin)
- **Body:** `{ "requestStatus": "APPROVED" }`
- **Response `200 OK`:** Returns updated request status.

#### `GET /api/requests/user/:receiverId`
- **Access:** Private
- **Response `200 OK`:** List of requests made by the specified receiver.

### 3.7 Nearby NGO Matching Engine (Member 4)

#### `GET /api/matching/donations/:foodId/ngos`
- **Access:** Public
- **Query Params:** `radius` (in kilometers, default: `20`)
- **Description:** Algorithmic ranking of recipient NGOs using Haversine distance, transit feasibility, category alignment, and capacity.
- **Sample Response `200 OK`:**
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Found 3 nearby recipient NGOs within 20 km radius.",
  "data": {
    "donation": {
      "foodId": "food_001",
      "foodName": "Fresh Vegetable Curry & Rice",
      "category": "Cooked Meals",
      "quantity": "25 portions",
      "urgencyTier": "CRITICAL",
      "timeRemainingFormatted": "1h 28m remaining"
    },
    "searchRadiusKm": 20,
    "totalMatches": 3,
    "matches": [
      {
        "ngoId": "ngo_hope_shelter",
        "name": "Hope Community Shelter",
        "category": "Homeless Shelter & Kitchen",
        "contactPerson": "Sarah Jenkins",
        "phone": "+1-555-234-5678",
        "distanceKm": 0.61,
        "estimatedTransitMinutes": 6,
        "isTransitFeasible": true,
        "categoryMatch": true,
        "matchScore": 98
      }
    ]
  }
}
```

#### `GET /api/matching/nearby-donations`
- **Access:** Public
- **Query Params:** `lat`, `lng`, `radius` (km), `category` (optional)
- **Description:** Enables recipient shelters or volunteers to discover active food donations near their location.
- **Sample Response `200 OK`:** Returns array of nearby active food donations with calculated distance and transit ETA.

#### `GET /api/matching/ngos`
- **Access:** Public
- **Description:** Returns directory of verified recipient NGOs, locations, contacts, and capacity.

### 3.8 Pickup Deadline Warnings & Impact Projection (Member 4)

#### `GET /api/donations/warnings/expiring-soon`
- **Access:** Public
- **Query Params:** `hours` (threshold in hours, default: `5`)
- **Description:** Returns perishable food listings requiring urgent collection before expiry.
- **Sample Response `200 OK`:**
```json
{
  "success": true,
  "statusCode": 200,
  "data": [
    {
      "foodId": "food_001",
      "foodName": "Fresh Vegetable Curry & Rice",
      "pickupDeadline": "2026-11-13T12:30:00.000Z",
      "urgencyTier": "CRITICAL",
      "timeRemainingFormatted": "1h 28m remaining",
      "warningBadge": "CRITICAL WARNING",
      "deadlineAnalysis": {
        "urgencyTier": "CRITICAL",
        "hoursRemaining": 1.5,
        "minutesRemaining": 88,
        "isExpired": false,
        "priorityScore": 95,
        "warningMessage": "CRITICAL: Only 1h 28m remaining! Spoilage imminent. Dispatch immediate volunteer/NGO pickup."
      }
    }
  ]
}
```

#### `GET /api/stats/leaderboard`
- **Access:** Public
- **Description:** Community recognition leaderboard ranking top food donors and recipient impact.

#### `POST /api/stats/calculate`
- **Access:** Public
- **Body:** `{ "mealsSaved": 500 }` or `{ "kgFood": 210 }`
- **Description:** Computes dynamic environmental savings projections (CO2e, embedded water, economic value) based on EPA WARM models.
