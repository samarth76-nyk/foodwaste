# Frontend Pages Directory

This directory contains page-level components and route views for the ShareBite frontend application.

## Recommended Pages to Create:
- `HomePage.jsx` – Landing page with mission, call-to-actions, and live stats overview.
- `DonationsPage.jsx` – Browse and search active food donations.
- `CreateDonationPage.jsx` – Donation creation interface for food donors.
- `RequestsPage.jsx` – Track incoming and outgoing food requests.
- `AdminDashboardPage.jsx` – Administrative control panel with stats, user management, and audit logs.
- `LoginPage.jsx` / `RegisterPage.jsx` – Authentication pages.

## Routing:
You can install React Router DOM if desired:
```bash
cd client
npm install react-router-dom
```
Then configure your routes inside `client/src/App.jsx`.
